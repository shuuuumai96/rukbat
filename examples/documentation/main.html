main.rukbat

List CSV files

Prints the number of CSV files directly inside the supplied directory. No files are created, changed, or removed.

rukbat run main.rukbat -- C:/Data

Supply exactly one directory argument. Invalid arguments or listing failures produce a diagnostic on stderr and exit code 1. Success exits with code 0. The reusable function is files.list_csv.
