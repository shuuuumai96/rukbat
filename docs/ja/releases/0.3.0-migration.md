# 0.2.0から0.3.0への移行案内

[リリースノート（英語）](../../releases/0.3.0.md)もあわせて参照してください。

## 関数・メソッド宣言の `: void` を省く

0.3.0では、関数・メソッド宣言の `: void` を廃止しました。
0.2.0で予告したとおり、旧表記は構文エラー（`RUK1000`）になります。`rukbat fmt` による自動変換もありません。

移行前（0.2.0）：

```rukbat
fn save(path: string): void {
    print(path)
}
```

移行後（0.3.0）：

```rukbat
fn save(path: string) {
    print(path)
}
```

`: void` を書いたソースが残っている場合は、**0.3.0へ上げる前に 0.2.0 の `rukbat fmt` を実行して省略形へ揃えてください**。
PowerShellの出力を破棄する `powershell<void>` は、そのまま使えます。

## 予約語 `enum` とぶつかる名前を変える

`enum` が予約語になりました。
ユーザー定義の `enum` 宣言を追加したためです。変数・引数・関数・構造体・フィールド・import別名などに `enum` を使っている場合は、別の名前に直してください。

## 生成済みスクリプトを入れ替える手順

1. 0.2.0のコンパイラ、ソース、生成済み `.ps1` を退避します。
2. `: void` が残っている場合は、0.2.0の `rukbat fmt` で省略形へ変換します。
3. コンパイラとVS Code拡張を0.3.0へ揃えて更新し、自動処理のバージョンを固定します。
4. `enum` との名前衝突を直し、`rukbat fmt --check`、`rukbat check`、`rukbat test` を通します。
5. `rukbat build` で `.ps1` を再生成し、配布先と同じ条件で動かしてから入れ替えます。

コンパイラを更新しただけでは、過去に生成した `.ps1` は変わりません。
0.3.0公開をもって0.2.0の保守は終了しますが、旧版のタグと配布物は再現性のため残します。
