# 0.3.0 acceptance record

Updated: November 28, 2026 (Japan time).

## Final Windows x64 packages

Source commit: `68418a6b4eccd197cfe495700d8e4611ab4f45c5` (`v0.3.0`).
The final CLI ZIP and VSIX were built from this clean revision using
`tools/package.ps1`. Both extracted runtimes passed `tools/test-distribution.js`
with system .NET excluded from the child PATH and `DOTNET_ROOT` redirected, and
the extracted VSIX passed the VS Code editor suite (`npm run test:editor`) with
its bundled compiler. Both PowerShell hosts (`powershell` 5.1 and `pwsh` 7)
passed standalone source-free execution checks for 0.3.0 features (`enum`,
`csv.rows`, and `fmt --check`) in a separate directory. The bundled `rukbat.exe`
executable matched identically between packages.
