# Rukbat 0.3.0 preview

**Windows x64 evaluation preview.** Use it at your own risk. Offline operation
on a clean Windows installation without a separate .NET SDK or runtime has
not been verified. Test in your own environment before relying on it for automation.

## Scope

This preview adds user-defined `enum` types, streaming file/CSV and operational
scripting APIs, canonical format checking (`rukbat fmt --check`), and generated
PowerShell startup/runtime optimizations, and removes the deprecated `: void`
declaration form announced in 0.2.0. It remains an evaluation release; later
0.x releases may change source compatibility.

## Migrating from 0.2.0

[日本語の移行案内](../ja/releases/0.3.0-migration.md)

### Remove explicit `: void` on function and method declarations

As announced in 0.2.0, explicit `: void` annotations on function and method
declarations are no longer accepted and now produce a syntax error (`RUK1000`).
The formatter no longer rewrites `: void` declarations automatically.

Before (0.2.0):

```rukbat
fn save(path: string): void {
    print(path)
}
```

After (0.3.0):

```rukbat
fn save(path: string) {
    print(path)
}
```

If you have existing `.rukbat` sources that still use `: void` on function or
method declarations, run `rukbat fmt` with **0.2.0** before upgrading to 0.3.0.
`powershell<void>` remains unchanged as the explicit instruction to discard
PowerShell output.

### Rename identifiers spelled `enum`

`enum` is now a reserved keyword for user-defined enum declarations. Rename any
existing variables, parameters, functions, structs, fields, or import aliases
using that spelling.

### Rebuild deployed scripts

Pin the compiler version, update sources, run `rukbat check` and `rukbat test`,
then rebuild and validate generated `.ps1` scripts on the target host before
replacing deployed artifacts. Updating the compiler does not update previously
generated `.ps1` files.

## Changes since 0.2.0

The source changes include:

- **User-defined enums:** Declare fixed sets of named values with `enum` at
  module scope, reference members as `Type.member`, compare with `==` / `!=`,
  convert with `text.parse_enum<T>` and `text.from_enum`, and serialize/parse
  as strings in typed JSON.
- **Explicit `: void` declaration removal:** Reject `: void` on function and
  method declarations with a syntax error directing users to omit the return
  annotation, and remove the temporary 0.2.x formatter conversion.
- **Streaming and operational scripting APIs:**
  - `csv.records(path, encoding)` and `csv.rows(path, encoding, required_columns)`
    for sequential CSV processing.
  - `fs.walk_files(directory, pattern)` for streaming recursive file discovery.
  - `fs.stage_text(path, encoding)`, `fs.write_chunk(writer, text)`, and
    `fs.commit(writer)` for scoped atomic text output.
  - `fs.try_lock(path)` for scoped exclusive file locking and `fs.error_kind(error)`
    for classifying I/O errors.
  - `json.parse_strict<T>(text)` to reject undeclared properties in typed structs.
  - `process.sleep(duration_ms)`, `process.monotonic_ms()`, and
    `process.run_to_files(...)` for operational timing and direct raw output capture.
- **Format checking:** Add `rukbat fmt --check <file-or-directory>` to verify
  canonical formatting without rewriting files.
- **Performance and generated PowerShell optimizations:** Skip empty standard
  library modules, eliminate redundant value clones for fresh/read-only/immutable
  values, split and lazily load runtime helpers, and reduce CSV table allocations.

This list describes changes in source; it is not evidence that final packages
have passed acceptance.
